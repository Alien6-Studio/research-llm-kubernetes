# Experimental runs

Working collection files are ignored. Emulator collections, native inference
observations, technical controls and excluded blocks remain separately
identifiable in the public lossless archives and evidence indexes.

`python3 scripts/check_cpu_continuation.py --restore-only` reconstructs the
nineteen original-prefix files, 185 continuation files and retained calibration
pilot at their exact paths without a model server. Existing different bytes are
never overwritten.
